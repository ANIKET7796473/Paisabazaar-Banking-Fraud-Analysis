# 💳 Credit Card Fraud Detection Analysis

## 📌 Project Overview

This project analyzes credit card fraud transactions using the **Paisabazaar Banking Fraud Detection Dataset**. The primary objective is to explore transaction patterns, identify fraudulent activities, and generate meaningful insights through data analysis and visualization.

The project demonstrates how Python libraries such as **Pandas, NumPy, Matplotlib, and Seaborn** can be used for data preprocessing, exploratory data analysis (EDA), and visualization, while **Power BI** is used to build an interactive dashboard for business insights.

---

## 🚀 Features

- 📊 Data Cleaning and Preprocessing
- 📈 Exploratory Data Analysis (EDA)
- 💳 Fraud vs Legitimate Transaction Analysis
- 📉 Transaction Amount Analysis
- 📍 Fraud Trend Analysis
- 👤 Customer Transaction Insights
- 📊 Interactive Power BI Dashboard
